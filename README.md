# 文本加密（Text Encrypt）

思源笔记插件：用密码加密选中的文本，加密后内容会被标注，只有输入密码才能查看明文。

![预览图](preview.png)


## 功能

- 加密：选中一段文本后右键 →「加密」→「设置加密」，输入两次密码后，选中内容会被 AES-256-GCM 加密并替换为密文。支持整块加密，也支持只加密块内的一部分文字。
- 标注：加密后块的属性会写入 `custom-encrypted: 🔒 已加密`（在「块属性」面板可见），块上方左侧显示单个 🔒 图标（不遮挡文字），并带琥珀色背景和左侧色条。
- 解密查看：重新选中加密内容后右键 →「加密」→「解密查看」（此时不再显示「设置加密」），输入密码后弹窗显示明文，可复制。
- 恢复明文：解密弹窗中可「解密并恢复为明文（移除加密）」。

## 使用

1. 将 `siyuan-plugin-text-encrypt` 文件夹复制到工作空间 `data/plugins/` 下。
2. 重启思源（或刷新插件列表），在「设置 → 插件」中启用「文本加密」。
3. **推荐用法（桌面端与移动端通用）**：选中文本后，点击浮动工具栏里的 🔒 按钮。插件会自动判断：普通文本弹出「设置加密」，含密文则弹出「解密查看」。
4. 桌面端右键菜单：思源 3.8 起插件菜单收在「插件」子菜单内，路径为 右键 →「插件」→「加密」→「设置加密 / 解密查看」。
5. 顶栏入口：桌面端点击顶栏「插件」图标、移动端从侧边抽屉菜单选择「文本加密」，可打开「加密选中文本 / 解密查看选中文本」菜单（打开菜单会取消当前选区，移动端建议使用第 3 步的工具栏按钮）。

## 版本适配

- 适配思源 3.8.x：新增编辑器「选择工具栏」入口（`addToolbarItem`），兼容 3.8 的统一执行上下文（工具栏回调传入 `{protyle}` 包装对象）；3.8 以下版本自动回退为 `updateProtyleToolbar`。
- 修复存在隐藏页签时定位到错误编辑器、导致提示「所选区域没有可加密的文本块」的问题；恢复明文时也会跨编辑器正确定位块。
- 移动端修复（0.1.4）：复制明文改用思源自带剪贴板（`platformUtils`），不再依赖移动端不可用的 `navigator.clipboard`；点击工具栏后即使系统清空选区，也会回退到最近一次选区继续加密/解密；选中的内容含密文（或光标落在加密块内）时，右键/长按菜单会正确显示「解密查看」。
- 移动端键盘修复（0.1.5）：密码输入框聚焦后，弹窗会自动上移到可视区顶部并自适应高度，键盘不再遮挡输入框和按钮；输入框使用 16px 字号避免 iOS 聚焦时页面被放大；若键盘没自动弹出，点击弹窗任意空白处即可重新唤起。

## 支持的块类型

- 段落、标题（H1-H6）、列表项、引用块。
- 支持整块加密和块内部分文本加密。
- 对设置了忽略索引（indexignore）的文档同样可用，因为插件直接读写块内容，不依赖搜索索引。

## 安全说明

- 加密算法：PBKDF2-SHA256（25 万次迭代）派生密钥 + AES-256-GCM，随机盐和 IV 随密文一起保存。
- 密文以 `enc:v1:盐.IV.密文` 的形式存在块内容中，因此即使直接读取 `.sy` 文件、SQL 或全文搜索，看到的也只是密文。
- 密码只存在于你输入的那一刻，插件不保存密码；**忘记密码将无法恢复内容**。
- 该加密不保护文档标题、块类型等结构信息，只加密块文本内容。

## 已知限制

- 加密会失去选中文本原有的 Markdown 格式（加粗、斜体等），恢复后为纯文本。
- 如果选中区域跨多个块，只加密完全包含在选区内的块；边界块若无法精确定位选中文本，会跳过并提示。
- 同一个块不会重复加密（已含密文的块会被跳过）。
- 请勿对文档块（标题文档）执行加密。
